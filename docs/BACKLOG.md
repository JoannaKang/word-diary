## M0. 셋업

### M0-1. 화면 빌드 방식 확정
Apps Script HtmlService는 HTML 파일만 받습니다. 후보: TypeScript + Vite로 단일 HTML을 빌드해 인라인
(`vite-plugin-singlefile` 류) / 빌드 없이 바닐라 JS. 테스트·스크린샷 픽스처(CLAUDE.md 변경 규칙 4)를
돌리려면 전자가 유리합니다. **아직 코드가 없어서 안 정했습니다.** 정하면 결정 기록에 남기고
`CLAUDE.md` 「스택」·명령어 표, `package.json`(`check`·`shot`), `.nvmrc`를 맞춥니다.

### M0-2. ⛔ 배포 경로 — 사용자 선택 필요
컨테이너에는 사용자 Google 인증이 없어 `clasp push`를 못 합니다. 후보:
- **A. GitHub Actions 자동 배포** — 사용자가 로컬에서 `clasp login` 후 토큰을 저장소 Secret으로 등록 →
  푸시하면 테스트 배포에 반영. 폰만으로 확인 가능(지금 작업 방식과 맞음). 단, 그 토큰이 사용자 Drive에 접근하는
  권한을 가지므로 Secret 관리에 주의.
- **B. 사용자가 직접 반영** — 빌드 결과물을 Apps Script 편집기에 붙여넣기. 설정은 없지만 매번 손이 감.
사용자가 고르기 전에는 시작할 수 없습니다.

### M0-3. CI
`london-playtime`의 `.github/workflows/ci.yml`(typecheck → test → build)을 가져옵니다.
**`package.json`이 아직 없어서** 지금 넣으면 매 푸시가 실패합니다. M0-1 직후에.

### M0-4. 원본 업로드 크기 탐사
`google.script.run`으로 10MB 사진 원본을 보낼 수 있는지(PRD 9.3). 탐사 규칙대로 결과를 `docs/LEARNED.md`에
적고 코드는 지웁니다. **배포 경로(M0-2)가 있어야** 실제로 돌릴 수 있습니다.

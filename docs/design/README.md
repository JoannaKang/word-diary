| `mockups-c.html` | (ui, 비교용) `mockups.html`과 같은 구조·시나리오·예시·앵커를 C안 「수채 스크랩북」으로 그린 목업 — 수채 번짐은 머리·사진 뒤·빈 상태에만, 아이의 말은 Hi Melody. 두 페이지를 나란히 비교용 |

역할 분담:

- **ux 문서**는 구조·인터랙션·상태·문구만 정합니다. 색·폰트·px 값을 쓰지 않습니다.
- **ui**는 그 위에 값을 확정하고 토큰으로만 넣습니다. 컴포넌트에 색상 리터럴을 쓰지 않습니다.

출발점: `docs/PRD.md` 10장(화면 구성, 디자인 톤 — 따뜻한 종이 질감의 일기장, 아이의 말은 큰 인용구).

## 1. 한 줄 컨셉

**엄마가 크림색 다이어리에 만년필로 적고, 아이의 말만 크게 손글씨로 받아 적어 사진 한두 장을 테이프로 붙여 둔 페이지.**

출발점: 사용자 요청(엄마가 직접 쓰는 육아일기, 아날로그 다이어리를 쓰는 느낌)과 PRD 10장
「따뜻한 종이 질감의 일기장, 아이의 말은 손글씨 느낌의 큰 인용구, 영어/한국어 모두 잘 보이는 폰트」.

## 2. 무드 키워드와 피할 것

| 무드 키워드 | 화면에서 뜻하는 것 |
|---|---|
| **손으로 쓴** | 손글씨 서체는 *아이의 말*에만. 엄마의 글은 단정한 명조 — 「받아 적은 사람」과 「말한 사람」의 목소리가 갈린다 |
| **크림 종이** | 순백이 아닌 따뜻한 미색 바탕, 아주 옅은 종이 결 |
| **정돈된 다이어리** | 모눈(4px 체계와 맞물리는 16px 격자)이 질서를 준다. 꾸미기보다 **기록** |
| **문구의 작은 흔적** | 날짜 도장, 마스킹테이프 한 조각, 인화 사진 테두리 — 각각 「한 번씩만」 |
| **조용함** | 그림자는 종이 한 장 두께만큼. 애니메이션은 넘기는 느낌 정도 |

| 피할 것 (anti-mood) | 왜 |
|---|---|
| **2010년대식 스큐어모피즘** — 가죽 표지, 실밥 바느질, 종이 찢긴 가장자리, 링 바인더 | 「아날로그 느낌」이 아니라 「아날로그 흉내」로 읽힌다. 주목을 기록이 아니라 장식이 가져간다. 최근 스큐어모피즘이 돌아오더라도 2010년대보다 훨씬 절제된 형태라는 관찰이 있다(참고 R7) |
| **과한 텍스처** — 글자 아래 무늬, 진한 크라프트 결 | 손글씨 서체는 획이 불규칙해서 바탕 무늬와 겹치면 판독성이 먼저 무너진다. 무드보드 마지막 「과함」 견본이 그 예 |
| **뉴모피즘(볼록·오목 그림자)** | 경계 대비가 낮아 버튼이 바탕에 묻힌다 — 접근성 비판이 많다(R8) |
| **얇은 손글씨 본문** | Nanum Pen Script 같은 얇은 펜 서체를 15px 메모·UI에 쓰면 읽히지 않는다. 손글씨는 크게, 짧게만 |
| **꾸미기 앱 감성** — 스티커 팩, 반짝이, 이모지 뿌리기 | 「다꾸」 앱(R5·R6)은 꾸미는 재미가 본체다. 이 앱의 본체는 30초 기록(PRD 6장)과 아이의 말 — 장식을 고르는 단계가 생기면 안 된다 |
| **사진 필터·두꺼운 프레임** | 사진은 아이의 순간이다(ui 원칙). 인화 테두리는 흰 여백일 뿐, 색 보정·비네팅 없음 |
| **파스텔 유아 톤**(하늘·분홍 원색 파스텔) | 「아기 앱」이 되면 엄마의 일기라는 결이 사라진다. 색은 종이·잉크·도장에서만 가져온다 |

### 3.3 확인 못 한 것

- **fonts.google.com 페이지는 이 컨테이너에서 DNS 실패로 못 읽었다.** 대신 `fonts.googleapis.com` CSS API(모든 후보 200 응답)와
  `google/fonts` 저장소의 `METADATA.pb`(디자이너·굵기·서브셋)로 확인했다.
- 호보니치 종이 색: JetPens A6 사진은 크림색인데 A5 목록은 「White」로 적혀 있어 출처끼리 엇갈린다. 색값은 실물 측정이 아니라 눈대중 — `paper` hex는 우리 결정이다.
- 폴라로이드 치수는 소매점·Q&A 자료뿐, Polaroid 공식 사양은 읽지 못했다.
- 마스킹테이프(mt 등)·날짜 도장·만년필 잉크 색은 웹 출처를 따로 찾지 않았다(일반 관찰).
- Day One 실제 화면 스크린샷은 보지 못했다(비평 글로만 확인).
- 국내 육아일기 앱 화면(베이비그램 등)은 App Store 소개글만 확인, 화면은 못 봤다.

같은 기록 카드로 비교 — `moodboard.html` A·B·C 절.

| | A. 크림 모눈 다이어리 | B. 크라프트 줄노트 | C. 수채 스크랩북 |
|---|---|---|---|
| 한 줄 | 크림 종이 + 옅은 모눈, 블루블랙 잉크, 주홍 날짜 도장 | 갈색 크라프트지 + 줄노트, 세이지 테이프 | 흰 종이 + 복숭아·세이지 수채 번짐 |
| 아날로그감 | 높음 (정돈된 다이어리) | 가장 높음 (빈티지) | 중간 (앨범·스크랩북) |
| 아이의 말 판독성 | ink 13.99:1 | ink 12.43:1, 바탕이 어두워 손글씨가 무거워 보임 | ink 13.08:1 |
| 사진과의 궁합 | 좋음 — 크림이 사진을 따뜻하게 감싸되 색을 바꾸지 않음 | **나쁨** — 갈색 바탕이 사진 색을 탁하게 보이게 함 | 가장 좋음 |
| 대시보드로 확장 | 모눈이 그대로 펼침면 묶음의 정렬 격자가 된다 | 줄노트는 목차·목록엔 맞지만 사진 묶음과 리듬이 어긋남 | 번짐을 묶음마다 쓰면 산만, 안 쓰면 그냥 흰 화면 |
| 장식 피로 | 낮음 | 중간 (결이 진해 매일 보면 무거움) | 높음 (번짐 반복) |
| 4px 체계와 | 16px 모눈 = 4px × 4로 맞물림 | 28px 줄 간격 — 본문 행간과 맞추기 까다로움 | 해당 없음 |

### 추천: **A. 크림 모눈 다이어리**

1. **아이의 말이 주인공으로 남는다.** 바탕이 가장 조용하면서도 순백보다 따뜻해서, 굵은 손글씨 인용구가 가장 먼저 읽힌다.
2. **사진을 덮지 않는다.** B는 바탕색이 사진 색감을 끌어내린다. A의 크림은 인화지(흰색) 테두리와 대비만 만든다.
3. **대시보드(ux의 「펼침면」)와 맞는다.** 묶음이 위아래로 쌓이는 펼침면에서 모눈은 장식이 아니라 정렬 격자가 되고, 목차 줄·인용·사진 묶음이 같은 격자 위에 놓인다. C의 수채는 카드 한 장일 때 예쁘고 화면 전체로 반복되면 산만하다.
4. **4px 간격 체계와 그대로 맞물린다**(16px 모눈).
5. B의 따뜻함은 A 안에서 `tape`(살구빛 테이프)·`accent`(주홍 도장)로 일부 가져온다.

## 5. 컬러 팔레트 (A안)

대비율은 WCAG 2 상대 휘도 공식으로 직접 계산(스크립트로 hex → sRGB 선형화 → (L1+0.05)/(L2+0.05)).
기준: 본문 4.5:1, 큰 글자(24px+, 굵게 18.66px+)·아이콘·입력란 경계 3:1.

| 역할 | hex | 쓰임 | 대비 (paper `#FBF6EA` / card `#FFFDF7`) | 판정 |
|---|---|---|---|---|
| `paper` | `#FBF6EA` | 화면 바탕 | — | — |
| `card` | `#FFFDF7` | 기록 카드·대시보드 묶음·입력 시트 | card↔paper 1.06 | 경계는 그림자로 (카드는 조작 요소가 아니라 3:1 대상 아님) |
| `ink` | `#2E2A26` | 아이의 말, 제목, 본문 | 13.20 / 13.99 | 통과 |
| `ink-soft` | `#655B50` | 엄마의 메모, 나이, 라벨 | 6.15 / 6.52 | 본문 통과 |
| `accent` | `#B0412C` | 날짜 도장, 저장 버튼, 커서, 여는 따옴표 | 5.35 / 5.67 | 본문 통과 |
| `on-accent` | `#FFFDF7`(=card) | 저장 버튼 글자 | on accent 5.67 | 통과 |
| `ink-blue` | `#2F4A6B` | 태그, 링크 (만년필 블루블랙) | 8.42 / 8.93 | 통과 |
| `rule` | `#E3D8C2` | 구분선 | 1.31 | **글자 금지** — 장식 |
| `grid` | `#EEE5D3` | 모눈 선 | on paper 1.16 | **장식 전용** |
| `rule-strong` | `#8C7D6A` | 입력란 밑줄, 필수 경계 | 3.70 / 3.93 | 비텍스트 3:1 통과, **본문 글자로는 불가** |
| `tape` | `#E9C9A8` (불투명도 0.78) | 마스킹테이프 | ink on tape 9.07 · ink-soft on tape **4.23** | 테이프 위 글자는 `ink`만 |
| `print` | `#FFFFFF` | 인화 사진 테두리 | — | — |

다른 방향안 값은 `moodboard.html` 스와치에 계산값과 함께 있다.

| 숫자 (대시보드·목차) | 문장 속 숫자는 메모 서체 그대로, 목차 줄 끝 수는 Gowun Dodum 13px `tabular-nums` | — | — | ux `scenarios.md` 3.2가 「KPI 판이 아니라 문장 속 숫자·목차」로 정함 — 큰 숫자 타일을 만들지 않는다. 목차 줄은 점선 리더(`rule-strong`)로 다이어리 목차 느낌 |

**손글씨 서체 사용 원칙**

- 손글씨는 **아이의 말에만** 쓴다(카드 인용구, 입력란의 아이의 말, 사진 캡션 정도). 버튼·라벨·날짜·메모·에러 문구엔 쓰지 않는다.
- 손글씨는 **24px 미만으로 줄이지 않는다.** 목록이 촘촘해져도 크기를 줄이는 대신 말 길이를 말줄임하는 쪽을 ux와 정한다(Q2).
- 한 화면에 손글씨 덩어리가 너무 많으면 효과가 사라진다 — 대시보드에서 손글씨 인용구는 「주인공」 자리에만.
- `word-break: keep-all` + `overflow-wrap: anywhere` — 한글 어절은 지키고, 긴 영어 단어(긴 공룡 이름)는 넘치지 않게.

## 7. 질감·장식·사진·아이콘·모션

### 7.1 질감과 장식 — 사용 상한

| 모티프 | 어디에 | 상한 (여기서 멈춤) |
|---|---|---|
| 종이 결 (인라인 SVG 노이즈) | `paper` 바탕 전체 | 불투명도 **≤ 0.05**. 카드·입력란 위엔 없음 |
| 모눈 16px | `paper` 바탕만 | 선 색 `grid`(1.16:1). **카드 안·글자 아래엔 절대 없음** |
| 마스킹테이프 | 기록 카드 상단 | **카드당 1개**, 회전 ±3° 이내. 사진 붙은 카드만 쓰는 안도 가능(Q3). 테이프 위엔 글자 없음 |
| 날짜 도장 | 카드의 날짜 | 테두리만, 회전 −2°. 채움·잉크 번짐 효과 없음 |
| 그림자 | 카드·인화 사진 | `0 2px 8px` 수준 한 겹. 드롭섀도 겹겹이·볼록 효과 없음 |
| 책갈피 | (후보) 현재 달·필터 표시 | 쓸지 여부는 대시보드 구조가 정해진 뒤 (Q5) |
| 금지 | 가죽·링 바인더·찢긴 가장자리·실밥·스티커 팩·반짝이 | — |

### 7.2 사진

- **인화 프레임**: 흰 테두리 위·옆 6px, 아래 22px(폴라로이드 비율 축소, R3). 회전 ±1.5° 이내, 한 줄에 여러 장이면 번갈아.
- 아래 여백에 짧은 손글씨 캡션 가능(선택).
- **사진 자체는 손대지 않는다**: 필터·색보정·비네팅·세피아 금지, `object-fit: cover`로 자르기만.
- 사진이 하나뿐이고 큰 경우(상세 화면)는 프레임 없이 모서리 4px만 — 프레임이 사진을 작게 만들 때는 프레임을 뺀다.

### 7.3 아이콘·일러스트

- **선 아이콘, 1.5px 획, 둥근 끝** — 연필로 그은 느낌이되 손떨림 효과는 넣지 않는다. 색은 `ink-soft`(6.15:1, 아이콘 3:1 충분).
- 일러스트는 MVP에서 쓰지 않는다. 빈 상태(기록 0개)에 그림이 필요하면 단색 선화 한 점만(Q6).
- 이모지를 장식으로 쓰지 않는다(PRD 10장의 📷는 아이콘 자리 표시로 해석).

### 7.4 모션

- 원칙: **종이 한 장이 움직이는 만큼만.** 시간 150–250ms, `ease-out`.
- 바텀시트(빠른 기록)가 올라오는 것 = 메모지를 꺼내는 느낌의 단순 슬라이드. 3D 페이지 넘김(curl) 효과는 쓰지 않는다 — 무겁고, 30초 기록을 늦춘다.
- 월 이동 등 「페이지」 전환은 가로 슬라이드 + 페이드 정도. 구조는 ux가 정한 뒤.
- 저장 완료 = 날짜 도장이 「쿵」 찍히는 짧은 스케일(1.08→1) 1회 정도가 상한.
- **`prefers-reduced-motion: reduce`이면 모든 이동·회전 애니메이션을 끄고 즉시 전환**(불투명도 변화만 허용).

## 8. 검증 메모

- 무드보드 스크린샷(402×874, 전체 페이지, DPR 2): Playwright + `/opt/pw-browsers/chromium`.
  `document.fonts.check`로 6개 웹폰트 모두 **실제 로드됨**을 확인 — 폴백 서체로 찍힌 것 아님.
- 402px에서 `scrollWidth = 402`, 화면 밖으로 넘친 요소 0개.
- 견본 버튼·입력란 높이 44px. 견본의 간격 값은 4px 배수.
- 1차 스크린샷에서 Gaegu 인용구의 자간·어간이 지나치게 벌어져 보여 조였고, 모눈 선이 시끄러워 `rule`과 별도로 더 옅은 `grid` 토큰을 분리했다.
